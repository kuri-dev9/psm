# 업무등록 도우미 (크롬 확장)

사내 업무기록(Timesheet) 화면 오른쪽 아래에 **업무등록 도우미** 버튼을 붙인다.
누르면 패널이 열려 이번 달 근무시간·MM 실적을 보여주고, MM 비율대로 계획해 저장한다.

크롬·엣지에서 동작하고 Windows·Mac 모두 된다. 별도 프로그램 설치는 필요 없다.

## 설치·업데이트

[저장소 README](../README.md#크롬-확장-설치) 참고. 요약하면:

1. `git clone https://github.com/kuri-dev9/psm.git`
2. `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
3. 업데이트는 `git pull` 후 `chrome://extensions`에서 새로고침(↻)

## 사용법

### 요약 탭

- **달력**: 프로젝트별 색상 막대로 등록한 시간을 보여준다(8h = 칸 전체, 왼쪽 오전 · 오른쪽 오후). 지출이 있는 날은 ₩ 표시, 칸에 마우스를 올리면 내역이 나온다.
- **잠금**: 기록이 있는 날을 누르면 잠금(🔒) ↔ 해제가 바뀐다. 아래 [잠금](#잠금) 참고.
- **내 최종 근무시간** = 영업일 × 8h − 연차 × 8h − 반차 × 4h ± 근무시간을 바꾼 날의 차이
- **프로젝트별 실적**: 배정MM · 목표시간 · 실적 · 남은시간 · 달성률
- 등록된 식대·교통비

### 계획·저장 탭

1. **휴가 지정**: 달력에서 날짜를 누를 때마다 근무 → 연차 → 오전 반차 → 오후 반차 순서로 바뀐다.
   업무기록 화면에 등록된 연차·반차는 패널을 열 때마다 자동으로 읽어 온다. 잠긴 날은 누를 수 없다.
2. **근무시간**: 칸 오른쪽 위의 시간 콤보박스에서 그날 근무시간을 30분 단위로 고른다.
   출근은 그대로 두고 퇴근을 계산한다 (점심 1h 공제, 8h를 넘으면 저녁 1h도 공제. 9.5h = 09:00~20:30).
   오전 반차도 14:00 출근에서 뒤로 늘릴 수 있다 (4h를 넘으면 저녁 1h 공제).
   휴가 상태를 바꾸면 그날 고른 근무시간은 지워진다.
3. **달력 막대**: 첫 줄은 지금 기록(진한 색 = 등록, 연한 색 = 예상), 바뀌는 날은 그 아래 새 계획이 나오고 지금 기록은 얇은 빗금으로 바뀐다.
   연차·반차는 막대 안에 `연차` / `오전` / `오후`로 표시한다.
4. **프로젝트별 막대** (달력 아래): 진한 부분은 등록된 시간, 연한 부분은 계획대로 저장했을 때 늘어나는 시간이다. 오른쪽은 `등록 % → 저장 후 %`.
5. **오늘까지만 입력**(기본 켬): 계획은 월 전체로 세우고, 저장은 오늘까지만 한다.
6. **계획** 목록에서 날짜별로 바뀔 내용을 확인하고 **저장**.
   저장 후 업무기록 화면을 새로고침하면 달력에 반영된다.
7. **원래대로**(왼쪽 아래): 이 달에 패널에서 바꾼 휴가·반차·근무시간을 지우고 시스템에 등록된 상태로 돌아간다. 잠금은 그대로 둔다.

### 설정 탭

- 기본·야근식대비 등록일·교통비 등록일의 출퇴근 시각 (기본 09~18시, 09~21시, 09~24시)
- 하루 최대 프로젝트 수, 프로젝트당 WBS 최대 라인 수
- **끝수를 연장근무로 맞춤**(기본 켬)과 하루 최대 연장 시간(기본 2h). 아래 [배분 방식](#배분-방식) 참고.
- 값을 바꾸면 바로 저장된다. **기본값으로 되돌리기**로 초기화할 수 있다.

## 잠금

- 잠긴 날은 계획·저장에서 그대로 두고, 그날 시간은 실적으로만 센다. 패널에서 휴가를 지정해 둔 날이라도 잠그면 기록을 그대로 둔다.
- 기본값: **직접 입력한 날은 잠금, 패널이 저장한 날은 해제.**
  서버가 작성자를 알려주지 않으므로, 패널이 저장할 때 그날 기록(행 ID·프로젝트·작업·시간·출퇴근)을 기억해 두고 지금 기록이 그것과 같으면 패널 입력으로 본다. 나중에 손으로 고친 날은 자동으로 잠긴다.
- 기억은 브라우저 저장소에 있으므로 다른 PC·브라우저에서 저장한 날은 직접 입력으로 보여 잠긴다.
- 시스템에 연차로 등록된 날은 잠그지 않는다.

## 배분 방식

- 목표시간 = 최종 근무시간 × 프로젝트 MM 비율 (30분 단위, 합계 정확히 일치)
- 하루를 한 프로젝트로 채우는 것을 우선하고, 맞지 않는 날만 4h씩 나눈다. 같은 프로젝트는 하루에 한 줄만 등록한다.
- **끝수 연장**(기본 켬): 4h 단위로 안 떨어지는 끝수를 기본일의 연장근무(8.5h, 9h …)로 붙여 프로젝트별 시간을 MM 비율과 정확히 맞춘다. 그만큼 최종 근무시간이 늘어난다(프로젝트가 많으면 한 달 10시간 이상).
  끄면 4h 단위로 맞추고 프로젝트별로 몇 시간 차이를 허용한다.
- WBS 라인이 여럿이면 MM 상위 라인만 쓰고 날짜별로 번갈아 써서 월 전체 비율을 맞춘다.

## 출퇴근 시간

- 업무기록 화면에 월 기본 근무시간이 등록돼 있으면 그날 등록된 시간을 출퇴근으로 쓴다.
  야근식대비·교통비 날은 출근만 등록 시간을 따르고, 퇴근은 설정의 시간 규칙과 등록 시간 중 늦은 쪽을 쓴다.
- 등록된 근무시간이 없을 때만, 업무기록 화면의 월 기본 근무시간이 패널의 기본 시간과 다르면 계획·저장 탭 맨 위에 **시스템에 적용** 버튼이 나온다(업무기록 화면이 같은 달을 보고 있을 때만).

## 동작 원칙

- 기존 줄은 **행 ID를 유지한 채 수정**한다. 초기화(그날 전체 삭제)는 쓰지 않는다.
- **본인 확인이 끝난 날은 건드리지 않는다.** `확인` 처리도 하지 않는다.
- 식대·교통비는 다른 시스템에서 등록하면 자동으로 감지한다.
- 반차: 오전 반차 14:00~18:00, 오후 반차 09:00~13:00 (근무 4h, 휴가 4h, 식사 미공제).
- 설정·휴가 지정·잠금은 이 브라우저에만 저장된다.

## 주의

- 업무기록 앱의 내부 API를 쓰므로 앱이 바뀌면 동작하지 않을 수 있다. 저장 전에는 항상 변경안을 확인할 것.
- 회사 규정상 업무기록 자동 입력이 허용되는지 먼저 확인할 것.
