# 업무등록 도우미

사내 업무기록(Timesheet)을 **WBS에 배정된 MM 비율대로** 채워 주는 도구다.

- 이번 달 최종 근무시간과 프로젝트별 목표·실적·달성률을 한눈에 보여준다.
- 휴가·반차·야근식대·교통비를 반영해 날짜별 계획을 세우고, 확인한 뒤 한 번에 저장한다.
- 직접 입력한 날은 잠가 두고 건드리지 않는다. 본인 `확인` 처리는 하지 않는다.

크롬·엣지 확장 프로그램이다. Windows·Mac 모두 되고, 다른 프로그램은 설치할 필요 없다.

> ⚠️ 업무기록 앱의 내부 API를 쓴다. 앱이 바뀌면 동작하지 않을 수 있으니 **저장 전에 항상 변경안을 확인**할 것.
> 회사 규정상 업무기록 자동 입력이 허용되는지도 먼저 확인할 것.

---

## 크롬 확장 설치

### 1. 받기

```bash
git clone https://github.com/kuri-dev9/psm.git
```

git이 없으면 GitHub 페이지의 **Code → Download ZIP**으로 받아 압축을 풀어도 된다(이 경우 업데이트도 다시 받아야 한다).

### 2. 크롬에 등록

1. 크롬 주소창에 `chrome://extensions` 입력 (엣지는 `edge://extensions`).
2. 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다** → 받은 폴더 안의 **`extension` 폴더**를 선택한다.
4. 포털에 로그인한 뒤 업무기록 화면을 열면(이미 열려 있으면 새로고침) 오른쪽 아래에 **업무등록 도우미** 버튼이 생긴다.

로그인 화면이나 포털의 다른 화면에서는 아무것도 하지 않는다(아이콘에 "필요한 액세스 권한 없음"으로 보이는 게 정상).

### 3. 업데이트

```bash
cd psm
git pull
```

그다음 `chrome://extensions`에서 **업무등록 도우미**의 새로고침(↻)을 누르고, 업무기록 화면도 새로고침한다.
폴더를 옮기지 않는 한 다시 등록할 필요는 없다. 버전은 확장 카드에 표시된다.

## 사용법 요약

자세한 내용은 [extension/README.md](extension/README.md).

1. **요약** 탭에서 이번 달 최종 근무시간과 프로젝트별 달성률을 본다.
   - 기록이 있는 날을 누르면 **잠금(🔒) ↔ 해제**. 잠긴 날은 저장할 때 그대로 둔다.
   - 직접 입력한 날은 기본으로 잠긴다.
2. **계획·저장** 탭에서
   - 날짜를 눌러 근무 → 연차 → 오전 반차 → 오후 반차를 지정한다.
   - 칸의 시간 콤보박스로 그날 근무시간을 30분 단위로 바꾼다.
   - 달력 아래 막대로 프로젝트별 달성률(등록 + 저장 후 예상)을 확인한다.
   - 아래 계획 목록에서 바뀔 내용을 확인하고 **저장**.
   - 잘못 바꿨으면 왼쪽 아래 **원래대로**.
3. 저장 후 업무기록 화면을 새로고침하면 달력에 반영된다. **본인 확인은 직접** 한다.

설정·휴가 지정·잠금은 그 브라우저에만 저장된다.

## 개발

| 경로 | 역할 |
|---|---|
| `extension/` | 크롬 확장 본체. 이 폴더를 크롬에 등록한다 (`panel.js` = 화면·API 호출) |
| `core.mjs` | 계산 엔진 원본(순수 로직) |
| `build.sh` | `core.mjs` → `extension/core.js` 변환 |

- 계산 로직은 `core.mjs`에서만 고친다. 고친 뒤 `./build.sh`로 `extension/core.js`를 다시 만들어 함께 커밋한다.
- 확장을 고치면 `extension/manifest.json`의 `version`을 올린다.
